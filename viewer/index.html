Release notes

At every checkpoint each team's Writer agent drafts the "available now" section from its own memory. Each line is checked against what is really live on each platform. STALE means the feature was live on that platform earlier but isn't now, e.g. it was rolled back.

Checkpoint questions

On each checkpoint day the judge generates questions from the hidden truth table: is each feature available, is it on Android, how many distinct bugs are open, is it meeting its adoption target, plus a release-notes task for the Writer. Support and Analyst both answer every question, so disagreements inside a team count as contradictions. The truth column is never shown to agents.
